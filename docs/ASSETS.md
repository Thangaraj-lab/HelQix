# Third-party assets in use

All assets below are CC0 from Poly Haven (https://polyhaven.com/license: "Our assets are all licensed as CC0", checked 2026-10-27). The files are not in the repository; `python -I scripts/fetch_cc0_assets.py` downloads them into `assets-local/` and verifies the checksums the Poly Haven API publishes. Models are packed to one `.glb` with glTF-Transform and pass the Khronos glTF-Validator with 0 errors (tangent-space warnings only).
